# Agent Note: SDK cohort 0.2.2-rc.2

Status: implemented

## Problem

The pet plugin tracked 0.2.2-rc.1 while dsh-web moved to the published 0.2.2-rc.2 cohort. Declarations, lockfile resolutions, release-age exclusions and the bilingual README pairing must advance together, otherwise a standalone install of this repository resolves a cohort the supported host no longer runs.

## Decision

SDK development dependencies move to `^0.2.2-rc.2`; the host engine and peer floors move to `>=0.2.2-rc.2`. Cordis stays at `~4.1.0` and schemastery at `~3.19.0` because rc.2 still peer-requires those exact minor lines. The lockfile, the `packageExtensions` keys and `minimumReleaseAgeExclude` ledger, both README badges and the `README.i18n.yaml` pairing hashes move in the same commit.

No source adaptation is required: this repository touches rc.2 only through the `/client` subpath exports of the client packages plus type-only imports of `@deepseek-ai/dsh-agent` and `@deepseek-ai/dsh-llm`, so the removed `internal` subpaths and the changed `startActivation` / `drainChildren` / `drainDescendants` shapes have no call site here.

## Alternatives considered

**Keep rc.1 ranges and rely on caret satisfaction.** Rejected: `^0.2.2-rc.1` never selects a prerelease of a different identifier, so the range cannot reach `0.2.2-rc.2` and the repository would build against the retired cohort.

**Carry `@deepseek-ai/dsh-error` as a devDependency.** Rejected for this commit: rc.2 splits `HarnessError` out of `dsh-llm` and declares it a required peer, which pnpm reports as a warning under `autoInstallPeers: false`, but every touch point in this repository is type-only, so nothing loads at runtime and the artifact is unaffected. Adding an unused dependency would widen the manifest beyond the cohort move.

**Publish a new pet package version.** Rejected: no release was requested and the package version remains 0.4.17.

## Consequences

`pnpm install --frozen-lockfile --ignore-scripts` passes against the updated lockfile. The 22 script tests, `pnpm typecheck`, the full Vitest suite (53 files, 694 tests) and `pnpm build` pass. No package is published to npm; dsh-web consumes the rebuilt working tree through its satellite profile link.
