宠物插件随 dsh-web 家族对齐到统一版本。本版本重写了设置页的宠物卡片、移除目录诊断面板，并带上聚合外壳关闭宠物与挂载重放的修复。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-pet` 与安装方式不变；宠物资产的分发方式也不变（包内只内置默认宠物，其余按需从 `dsh-market.com` 下载到 `$DSH_HOME/pets/<id>/`）。设置页上的「目录诊断」面板已移除：它只展示信息，不承载任何设置项。

### 修复

- 聚合外壳里的宠物可以被关闭：开关不再被聚合行吞掉
- 上一次挂载尚未释放时被拒绝的挂载不再丢失：持有者退出后自动重放
- 设置卡片在宿主重新渲染后保持挂载，不再因 dispose 规格不匹配而卸载

### 其他改动

- 设置页的宠物卡片按官方布局席位重写，移除目录诊断面板
- README：展示工坊上最受欢迎的三个宠物

The pet plugin publishes on the family's aligned version. This release rewrites the settings-page pet card, drops the directory diagnostics panel, and carries the aggregate-shell off switch and mount replay fixes.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-pet` and its install path are unchanged, as is how pet assets are distributed: the package ships only the default pet, and the Workshop downloads the rest into `$DSH_HOME/pets/<id>/` on demand. The directory diagnostics panel is gone from the settings page; it only displayed information and carried no setting.

### Bug Fixes

- The pet can be turned off from inside the aggregate shell: the switch is no longer swallowed by the aggregate row
- A mount refused while the previous holder was still alive is no longer lost: it replays once the holder exits
- The settings card stays mounted across host re-renders instead of unmounting on a dispose-spec mismatch

### Other Changes

- The settings-page pet card is rewritten against the official layout seats, and the directory diagnostics panel is removed
- README: showcase the three most-liked Workshop pets
