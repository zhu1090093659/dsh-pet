本版本把宠物插件的交互面开放给同级插件：悬停面板接受插件注册的按钮，公告气泡从单槽改为按发布者分槽，宠物自己的状态气泡可以在设置里关掉。同时修好浮动界面读不到语言包、语音包台词被设置面板覆盖，以及设置表单在共享表单尚未就绪时过早落定这三处缺陷。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-pet` 与安装方式不变：布局仍持久化在 `$DSH_HOME/pet.json`，键名不变，新增设置项 `statusBubbles` 的默认值 `auto` 与旧行为完全一致。线协议只做加法：状态快照新增可选的 `panelActions`、`statusBubbles` 与公告数组 `announcements`，原有的单数 `announcement` 字段保留原语义，端点新增 `POST /api/pet/panel-action`；读不懂新字段的浏览器半端与旧宿主各自忽略它们，不构成破坏性变更。

### 新功能

- 悬停面板开放插件动作行：同级插件通过 `ctx.pet.registerPanelAction({ id, label, title?, order?, onSelect })` 在 Feed / Rename / Hide 之后追加自己的按钮，点击经 `POST /api/pet/panel-action` 回到注册插件自己的回调；重复注册同一 id 会替换旧动作，动作随注册插件的 fiber 一起释放（#6）
- 公告气泡按发布者分槽：`pet.announce` 由单槽改为以 `source` 为键的有界槽位表（上限 4），每个发布者保留自己的 TTL，不再互相顶掉；重复发布者原地刷新自己的气泡，两个不同节奏的发布者不会交换上下位置（#1812）
- 新增设置项 Settings > Pet > Status bubbles（`statusBubbles`，默认 `auto`，可关闭）：只关掉宠物自己的会话/状态气泡，互动反馈气泡与同级插件的公告气泡照常渲染（#6）

### 修复

- 浮动宠物改为通过框架的 locale seat（`ctx.locale.bind('pet')`）取文案，不再使用只识别 `en` 的模块内 `t` 函数；此前除英文外的一切语言都会回落到中文，而旁边的设置卡片已经是翻译过的
- 语音包台词层在设置路径上不再丢失：所有 seating 路径统一经 `remarkLayers()` / `applyRemarks()` 同时解析 manifest 层与语音包层，`applySettingsSection()` 不再只传 `selected.remarks`（#10）
- 设置表单在共享表单报 `loading` 时不再过早落定：`fallbackSettled()` 现在只把 `ready` 判为已落定，因此有界重试窗口会保留到家族表单发布为止（#1813）

### 其他改动

- 新增宠物开发者 skill（`.agents/skills/dsh-pet-developer/SKILL.md`）
- Agent Note：记录 2026-10-05 的公告分槽与面板动作决策，以及 2026-10-06 的插件评审轮次与 locale seat 缺陷分析
- README：补充多发布者公告、插件面板动作与状态气泡开关的双语文档
- 测试：为宠物目录级 `voice.json` 台词层补上经设置路径的回归用例

This release opens the pet plugin's interactive surfaces to sibling plugins: the hover panel now takes plugin-registered buttons, announcement bubbles move from a single slot to one slot per publisher, and the pet's own status bubbles can be switched off. It also fixes three defects: the floating surface could not reach a language pack, the settings surface overwrote the voice-pack remark layer, and the settings form settled before the shared form was ready.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field or profile format was renamed. The package name `@linxin666/dsh-pet` and its install path are unchanged: the layout is still persisted in `$DSH_HOME/pet.json` with unchanged keys, and the new `statusBubbles` setting defaults to `auto`, which is exactly the previous behaviour. The wire change is additive: the state snapshot gains optional `panelActions`, `statusBubbles` and an `announcements` array, the singular `announcement` field keeps its previous meaning, and `POST /api/pet/panel-action` is new. A browser half or host that predates these fields ignores them, so nothing is broken.

### New Features

- Plugin actions in the hover panel: a sibling plugin adds its own button after Feed / Rename / Hide through `ctx.pet.registerPanelAction({ id, label, title?, order?, onSelect })`, and the click travels back to the registering plugin's own callback through `POST /api/pet/panel-action`. Registering the same id again replaces the earlier action, and the action is released together with the registering plugin's fiber (#6)
- Announcement slots per publisher: `pet.announce` moves from one slot to a bounded table keyed by `source` (at most 4), each publisher keeps its own TTL instead of displacing another, and a repeating publisher refreshes its own bubble in place so two publishers on different cadences never swap vertical positions (#1812)
- New Settings > Pet > Status bubbles switch (`statusBubbles`, `auto` by default, switchable off): it silences only the pet's own session/status bubbles, while the interaction feedback bubble and a sibling plugin's announcement bubble keep rendering (#6)

### Bug Fixes

- The floating pet resolves its copy through the framework locale seat (`ctx.locale.bind('pet')`) instead of a module-local `t` that distinguished only `en`; before this change every language but English fell back to Chinese while the settings card beside it was already translated
- The voice-pack remark layer is no longer dropped on the settings path: every seating path resolves both the manifest layer and the voice-pack layer through one `remarkLayers()` / `applyRemarks()` pair, and `applySettingsSection()` no longer passes `selected.remarks` alone (#10)
- The settings form no longer settles early while the shared form reports `loading`: `fallbackSettled()` now treats only `ready` as settled, so the bounded retry window stays open until the family form publishes (#1813)

### Other Changes

- New pet developer skill (`.agents/skills/dsh-pet-developer/SKILL.md`)
- Agent Notes: the 2026-10-05 announcement-slot and panel-action decisions, and the 2026-10-06 plugin review round and locale-seat defect analysis
- README: bilingual documentation for multiple announcement publishers, plugin panel actions and the status-bubble switch
- Tests: a regression case for a pet-directory `voice.json` remark layer applied through the settings path
