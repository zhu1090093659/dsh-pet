宠物插件随 dsh-web 家族对齐到统一版本。从本版本起，四个卫星仓与本仓发布同一个 X.Y.Z，卫星先发、本仓后发；版本号从 0.3.25 跳到 0.4.2 是这次对齐的结果。

> **重要变更**：本版本没有需要手工迁移的改动，没有重命名任何已持久化的标识符、线协议字段或 profile 格式。包名 `@linxin666/dsh-pet` 与安装方式不变。宠物资产的分发方式也不变：包内只内置默认宠物，其余宠物由工坊按需从 `dsh-market.com` 下载到 `$DSH_HOME/pets/<id>/`。

### 其他改动

- CI：pull request 自动路由到对应评审人；发布管线支持在同一 tag 上补跑（发布已成功但 registry 传播检查未过时，可直接重跑 dispatch 车道，无需重推 tag）
- 文本文件统一以 LF 检出

<summary>English</summary>

The pet plugin aligns to the dsh-web family's unified version. From this release on, the four satellite repositories publish the same X.Y.Z as this repository, satellites first; the jump from 0.3.25 to 0.4.2 is that alignment.

> **Important change**: no manual migration is needed, and no persisted identifier, wire-protocol field, or profile format is renamed. The package name `@linxin666/dsh-pet` and the install path are unchanged. Pet asset distribution is unchanged too: the package bundles only the default pet, and every other pet installs on demand from `dsh-market.com` into `$DSH_HOME/pets/<id>/`.

### Other Changes

- CI: pull requests are routed to their reviewers automatically, and the release pipeline can complete a tag that already published (re-run the dispatch lane instead of re-pushing the tag when only the registry propagation check failed)
- Text files check out with LF line endings
