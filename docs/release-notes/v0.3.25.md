宠物插件迁出 dsh-web 主仓后的首次独立发布。包名 `@linxin666/dsh-pet` 与安装方式不变，版本线从本版本起独立推进。

> **重要变更**：本版本没有需要手工迁移的改动，但相对 npm 上现存的 0.3.24 修复了一个会让插件完全无法激活的缺陷。此前发布的 0.3.24 仍然注入 0.1.7 已下线的 `settingsScope` 服务（构建产物里出现 19 处），在 0.1.7-rc.1 宿主上挂载会停在等待 `settingsScope`，永不激活。本版本随 0.1.7-rc.1 适配移除了该注入，挂载恢复正常。宠物资产的分发方式不变：包内只内置默认宠物，其余宠物由工坊按需从 `dsh-market.com` 下载到 `$DSH_HOME/pets/<id>/`，可随时安装与卸载。

### 新功能

- 独立仓库：宠物插件单独评审、单独发版，不再跟随主仓的统一版本
- 无需宿主表单即可持久化宠物选择（新增 `src/client/main-session.ts`）
- 插件列表图标（`icon.svg`）

### 修复

- 移除已下线的 `settingsScope` 注入，恢复在 0.1.7-rc.1 宿主上的激活

### 其他改动

- 仓库内置宠物校验/安装 CLI（`scripts/dsh-pet.cjs`）
- 新增 CI 与 tag 触发的发布管线
- 补齐 CONTRIBUTING 与仓库元数据

<summary>English</summary>

First standalone release after the pet plugin moved out of the dsh-web monorepo. The package name `@linxin666/dsh-pet` and the install path are unchanged; the version line advances on its own from here.

> **Important change**: no manual migration is needed, but this release fixes a defect that stopped the plugin from activating at all. The 0.3.24 currently on npm still injected the `settingsScope` service retired in 0.1.7 (19 occurrences in the built bundle), so mounting it on a 0.1.7-rc.1 host stalled waiting for that service and never activated. This release carries the 0.1.7-rc.1 adaptation that removes the inject, and mounting works again. Pet asset distribution is unchanged: the package bundles only the default pet, and every other pet installs on demand from `dsh-market.com` into `$DSH_HOME/pets/<id>/`, where it can be uninstalled again at any time.

### New Features

- Standalone repository: the pet plugin is reviewed and released on its own, no longer tied to the monorepo's unified version
- Persist the pet selection without a served host form (new `src/client/main-session.ts`)
- A listing icon for the plugin (`icon.svg`)

### Bug Fixes

- Drop the retired `settingsScope` inject and restore activation on a 0.1.7-rc.1 host

### Other Changes

- Carry the pet validate/install CLI in the repository (`scripts/dsh-pet.cjs`)
- Add CI and a tag-triggered release pipeline
- Add CONTRIBUTING and repository metadata
